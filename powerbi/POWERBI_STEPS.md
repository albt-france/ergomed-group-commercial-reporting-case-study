# Power BI: open, refresh, test RLS, export (about 10 minutes)

The model (TMDL, 18 tables, 34 measures, 4 roles) and the 5 pages (PBIR) are generated by `src/build_tmdl.py` and
`src/build_report_pages.py`. The data are the processed CSV files in `data/processed/`.

1. **Close Power BI Desktop**, then run `python src/run_all.py` (or only `src/build_tmdl.py` and `src/build_report_pages.py`).
2. Power BI Desktop: *File > Options and settings > Options > Preview features*: tick **Power BI Project (.pbip) save option**
   and **Store semantic model using TMDL format** if your version still lists them. Restart.
3. *File > Open* -> `powerbi/ErgomedCommercial.pbip`.
4. If the project is not in `C:\case-study-ergomed\`: *Transform data > Edit parameters > DataFolder* -> full path of
   `data\processed\` with a final backslash.
5. *Home > Refresh*. Check: page 1 shows about $256m won and 95% attainment for 2026; page 3 shows the waterfall for
   Ergomed CRO / Europe.
6. **Row-level security**: *Modeling > View as*:
   - tick `Region - Europe (static)`: only Europe remains on every page;
   - tick `Scoped user (business x region)` and *Other user* = `pv.na.manager@example.com`: only PrimeVigilance x North America;
   - `europe.lead@example.com` sees every business in Europe; `exec.team@example.com` everything (also role `Group leadership`).
7. *File > Save* (keeps the .pbip format).
8. **Captures for the PDF and README**: each page at 100% zoom (Win + Shift + S), saved as
   `docs/img/powerbi_p1.png` ... `powerbi_p5.png`. Then `python src/build_pdf.py` uses them.

If Power BI is not available, nothing breaks: the PDF says which views come from the model and which from the Python
pipeline, and the `.pbip` stays openable.
